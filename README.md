## Project Overview
This repository contains the complete implementation for Assignment 1, split into four functional parts:
- **Part 1 (Java):** ASCII value printer and character array parser (`hw1ASCII.java`).
- **Part 2 (Java):** Base-10 to binary/hexadecimal base converter with input validation (`hw1BaseConverter.java`).
- **Part 3 (Python):** Image pixel parser that extracts RGB values from an image and outputs mapped letter codes to `awesome_picture.txt` (`hw1readImage.py`).
- **Part 4 (Python):** Image reconstruction engine that reads `awesome_picture.txt` and renders `smiley2.png` (`hw1writeImage.py`).
